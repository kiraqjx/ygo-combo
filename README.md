# 决斗推演室 · YGO combo

纯前端的游戏王卡牌检索与「展开流程 + 手坑抗性」推演工具。技术栈：Vue 3 + TypeScript + Vite + Pinia + Vue Router。

## 功能

### 1. 卡牌检索

- 全卡池中文索引（约 14,300 张），本地检索、无需逐次请求。
- 支持按 **卡名 / 日文名 / 英文名 / 效果文本** 联合检索，多关键词空格分隔。
- 结构化筛选：卡片种类（怪兽 / 魔法 / 陷阱）、子类型（通常 / 效果 / 融合 / 同调 / 超量 / 连接 / 灵摆 / 调整 / 速攻 / 永续 / 反击…）、种族、属性、等级·阶级·连接、攻击力 / 守备力区间、灵摆刻度区间。
- 排序、无限加载、卡片详情抽屉（中文效果、日文名、英文名、卡号、连接标记）。
- 任意卡片可直接转成展开步骤 / 推演卡组 / 已知起手。

### 2. 展开工坊（流程树 + 检查点）

- 逐步搭建展开流程，选择卡片后自动从效果文本识别事件：检索、卡组特召、卡组送墓、墓地触发、可被遮蒙/泡影的场上怪兽效果等。
- 每一步记录状态快照：手牌数、场上怪兽、墓地数量、累计召唤次数。
- **检查点**：任意节点命名标记，实时显示该节点的手牌 / 场上 / 墓地状态，并作为手坑「收手点」的对比基准。
- **备线（Plan B）**：在任意节点分叉，绑定触发手坑。主线被该手坑判定断线时，引擎会改用备线判定能否继续。
- 资源链推演：步骤可声明「依赖资源 / 获得资源」，检索被封锁时，依赖该卡牌的后续步骤会连锁失效。
- 卡组感知补全：检索类效果会按文本条件（星级上限、种族、属性、「」内卡名、魔法/陷阱）在推演卡组中筛出可用目标。
- 展开数据保存在浏览器 localStorage，支持 JSON 导入 / 导出与复制。

### 3. 手坑抗性推演

内置 12 种常规手坑模型，逐项输出 **抽牌数、断点、能否打完、备线接管、收手点**：

| 手坑                  | 推演方式                                                         |
| --------------------- | ---------------------------------------------------------------- |
| 增殖的G               | 统计注入点之后所有**特殊召唤**次数                               |
| 山雀（茸茸长尾山雀）  | 只统计**从卡组 / 额外卡组**的特殊召唤                            |
| 水母（抖抖海月水母）  | 只统计**从手卡**的召唤 / 特殊召唤                                |
| 猫（喵喵豹猫）        | 只统计**从墓地 / 除外状态**的特殊召唤                            |
| 锁鸟                  | 注入点之后的「从卡组加入手卡」全部失效，并按资源链切断依赖步骤   |
| 灰流丽                | 可无效一次「卡组加手 / 卡组特召 / 卡组送墓」效果，再推演断线位置 |
| 效果遮蒙者 / 无限泡影 | 无效注入步骤的场上怪兽效果，怪兽仍在场                           |
| 原始生命态 尼比鲁     | 累计召唤·特召 ≥ 5 后场上清空，依赖场上怪兽 / 素材的步骤失效      |
| 次元吸引者            | 墓地取牌、墓地触发类步骤失效                                     |
| 屋敷童                | 从墓地取牌 / 特召 / 除外类效果失效                               |
| 幽鬼兔                | 破坏发动效果的场上卡片                                           |

补充机制：

- **自动最不利时机**：不知道对手何时丢手坑时，引擎会扫描所有可命中节点，取对展开最不利的结果；也可在右侧面板手动指定任意步骤为注入点。
- **可选步骤**：纯增益步骤标记为「可选」后，被无效只算终场缩减，不算断线。
- **综合抗性评分**：逐项评分取平均，输出 S / A / B / C / D 与 0–100 分。
- 时间线会用红色高亮当前所选手坑造成的失效步骤，并给出失效原因。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物输出到 dist/
npm run preview
```

纯静态站点。若部署到 Nginx 等服务器，请为 History 路由配置回退到 `index.html`：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

## 数据来源

- 卡牌数据：`https://ygocdb.com/api/v0/cards.zip`（中文卡库，约 2.4MB 压缩包）。首次打开时下载、解压并归一化，随后缓存到 IndexedDB，之后离线可用。
- 卡图：`https://cdn.233.momobako.com/ygopro/pics/{id}.jpg`，失败时回退 YGOPRODeck 图源。
- 卡库不可用时会自动退回 ygocdb 在线检索接口。

## 目录结构

```
src/
  lib/
    cardDb.ts      # 卡库下载 / 解压 / 归一化 / IndexedDB 缓存
    search.ts      # 检索与筛选
    infer.ts       # 效果文本 → 事件标记、卡组检索目标建议
    handtraps.ts   # 手坑模型定义
    engine.ts      # 状态快照、资源链模拟、抗性推演、评分
  components/      # 卡图、详情、选择器、步骤编辑器、流程树、抗性面板
  views/           # 总览 / 卡牌检索 / 展开工坊
  stores/          # Pinia：卡库、展开数据（localStorage 持久化）
  data/demoCombo.ts# 内置示例：英雄假面轴
```

## 说明与局限

- 推演是**基于事件标记的近似模型**，用于复盘与教学，不替代官方裁定。复杂连锁（多效果同一时点、效果外文本、特殊裁定）需要手动修正事件标记。
- 抽牌数按「手坑落地后仍成功执行的步骤」统计；如果某步被无效，则该步的召唤不计入抽牌。
- 陨石判定以「累计召唤次数」为阈值，并按场上怪兽依赖判断清场后的可续性。
